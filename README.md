# SomaInt

## Sobre o projeto

Exercício Java que lê dois números inteiros, calcula a soma e imprime o resultado.

## Como explorar

O arquivo declara a classe pública `Main`. Copie `SomaInt.java` para `Main.java` em uma pasta de trabalho. Execute `javac Main.java` e `java Main`; informe dois inteiros. Exemplo: `2 3` produz `SOMA É DE: 5`.
